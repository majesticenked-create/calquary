Lineare-Gleichung-Löser

Geben Sie die Koeffizienten für ax + b = c ein, um nach x aufzulösen.

Zuletzt aktualisiert: August 30, 2026

Häufig gestellte Fragen

Wie löse ich eine lineare Gleichung wie 3x + 5 = 20?

Isolieren Sie x: subtrahieren Sie 5 von beiden Seiten, um 3x = 15 zu erhalten, dann teilen Sie beide Seiten durch 3, um x = 5 zu erhalten. Allgemein gilt für ax + b = c: x = (c − b) / a.

Was ist, wenn die Gleichung x auf beiden Seiten hat, wie 2x + 3 = x + 10?

Bewegen Sie zuerst alle x-Terme auf eine Seite und Konstanten auf die andere: das Subtrahieren von x von beiden Seiten ergibt x + 3 = 10, dann ergibt das Subtrahieren von 3: x = 7. Ordnen Sie Ihre Gleichung in die Form ax + b = c um, bevor Sie sie hier eingeben.

Was bedeutet es, wenn a = 0 in diesem Rechner ist?

Wenn a 0 ist, gibt es keinen x-Term mehr zum Auflösen - die Gleichung wird einfach zu b = c. Wenn das wahr ist (wie 5 = 5), erfüllt jeder Wert von x sie; wenn es falsch ist (wie 5 = 7), kann kein Wert von x das, da der x-Term das Ergebnis nicht ändern kann.
