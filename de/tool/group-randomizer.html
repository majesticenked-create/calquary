Gruppen-Randomisierer

Geben Sie einen Namen pro Zeile ein und wählen Sie, in wie viele Gruppen sie aufgeteilt werden sollen - jede Gruppe wird zufällig und gleichmäßig zugewiesen.

Zuletzt aktualisiert: August 30, 2026

Häufig gestellte Fragen

Wie randomisiert dies Gruppen fair?

Es verwendet einen Fisher-Yates-Shuffle - einen bewährten Algorithmus, der jedem Namen eine gleiche, unvoreingenommene Chance gibt, an jeder Position zu landen - und teilt dann die gemischte Liste in Round-Robin-Reihenfolge in Gruppen auf, was die Gruppengrößen so gleichmäßig wie möglich hält.

Was passiert, wenn sich die Anzahl der Personen nicht gleichmäßig auf Gruppen aufteilen lässt?

Die zusätzlichen Personen werden beginnend mit der ersten Gruppe je eine pro Gruppe verteilt, sodass sich die Gruppengrößen um höchstens eine Person unterscheiden - bei 10 Personen aufgeteilt in 3 Gruppen erhalten Sie Gruppen von 4, 3, und 3, nicht 4, 4, und 2.

Kann ich dies für Klassenteams oder eine Arbeitsprojektaufteilung verwenden?

Ja - dies funktioniert für jedes Szenario, in dem Sie eine unvoreingenommene zufällige Aufteilung einer Namensliste in eine feste Anzahl von Gruppen benötigen, sei es für Klassenprojektteams, Sportteams, oder die Aufteilung einer Aufgabenliste bei der Arbeit.

Kann ich dies als Randomisierer verwenden, um einen zufälligen Gewinner auszuwählen oder Namen zufällig zu ordnen?

Ja - stellen Sie die Anzahl der Gruppen auf 1, und dieser Rechner mischt Ihre gesamte Liste in eine einzige zufällige Reihenfolge (die fairste Art, einen zufälligen Gewinner zu wählen, ist, denjenigen zu nehmen, der zuerst landet). Jedes erneute Mischen verwendet einen frischen Fisher-Yates-Shuffle.

Ist eine „Randomisierer-Liste“ oder „Liste randomisieren“ dasselbe wie dieses Tool?

Ja - beide beschreiben das Mischen einer Liste in zufälliger Reihenfolge, was dieses Tool tut (stellen Sie Gruppen auf 1 für eine einzige gemischte Liste, oder mehr für zufällige Gruppenaufteilungen).

Unterscheiden sich „Zufallsziehungen“, „Zufallslisten-Ersteller“, oder „Listen-Zufallsgenerator“ von diesem Tool?

Nein - all diese beschreiben das zufällige Ordnen oder Ziehen aus einer Liste, was dieser Rechner tut. Stellen Sie Gruppen auf 1, um die gesamte Liste in zufälliger Reihenfolge zu mischen.

Unterscheidet sich ein „Zufallsgenerator für Teams“ oder „Liste randomisieren“ von diesem Tool?

Nein - beide beschreiben das zufällige Aufteilen oder Mischen einer Namensliste, was genau das ist, was dieser Rechner tut. Stellen Sie die Anzahl der Gruppen auf die benötigte Anzahl von Teams, oder auf 1, um einfach die gesamte Liste zu mischen.
