Listen-Mischer

Fügen Sie eine Liste von Elementen ein (eines pro Zeile), um sie in zufälliger Reihenfolge zu mischen.

Zuletzt aktualisiert: September 1, 2026

Häufig gestellte Fragen

Wie zufällig ist diese Mischung?

Es wird der Fisher-Yates-Mischalgorithmus mit dem Zufallszahlengenerator Ihres Browsers verwendet, der jeder möglichen Reihenfolge eine gleiche Chance gibt - eine bewährte, unvoreingenommene Mischmethode.

Werden dabei doppelte Elemente aus meiner Liste entfernt?

Nein - es wird nur die von Ihnen eingegebene Liste neu geordnet. Wenn Ihre Liste Duplikate enthält, bleiben sie im gemischten Ergebnis; entfernen Sie sie zuerst aus Ihrer Eingabe, wenn Sie keine Wiederholungen möchten.

Wie unterscheidet sich dies vom Gruppen-Zufallsgenerator?

Dieses Tool ordnet nur eine einzelne Liste neu. Der Gruppen-Zufallsgenerator teilt stattdessen eine Liste von Namen in eine festgelegte Anzahl von Teams oder Gruppen auf - verwenden Sie diesen, wenn Sie Personen aufteilen müssen, nicht nur neu ordnen.

Kann ich dies verwenden, um die Reihenfolge einer Playlist, Verlosungsteilnehmer, oder Präsentationsreihenfolge zu randomisieren?

Ja - fügen Sie jede Liste (Songs, Namen, Themen) ein, eine pro Zeile, und es funktioniert für alle diese Anwendungsfälle auf die gleiche Weise.
