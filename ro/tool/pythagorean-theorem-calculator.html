Calculator de Teorema lui Pitagora

Introdu cele două catete ale unui triunghi dreptunghic pentru a calcula ipotenuza, folosind a² + b² = c².

Ultima actualizare: August 30, 2026

Întrebări frecvente

Ce este teorema lui Pitagora?

a² + b² = c², unde a și b sunt cele două laturi mai scurte (catete) ale unui triunghi dreptunghic și c este ipotenuza (latura cea mai lungă, opusă unghiului drept). Se aplică doar triunghiurilor dreptunghice.

Cum găsesc o catetă lipsă în loc de ipotenuză?

Rearanjează formula: a = √(c² − b²), sau b = √(c² − a²). Scade pătratul catetei cunoscute din pătratul ipotenuzei, apoi ia rădăcina pătrată.

Care este un exemplu comun al teoremei lui Pitagora, precum 3-4-5?

3-4-5 este cel mai comun "triplet pitagoric" - un set de numere întregi care satisfac exact a² + b² = c²: 3² + 4² = 9 + 16 = 25 = 5². Alte triplete comune includ 5-12-13 și 8-15-17, utile pentru verificarea rapidă dacă un colț este cu adevărat drept fără calculator.

Este un "calculator al teoremei lui Pitagora" diferit de acest instrument?

Nu - "Pitagora" și "pitagoric" se referă amândouă la aceeași teoremă și matematician. Toate aceste căutări vor același lucru: a² + b² = c², pe care acest calculator îl rezolvă pentru tine.
