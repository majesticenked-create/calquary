Întrebări frecvente

Care este diferența dintre medie, mediană, și mod?

Media este media aritmetică (sumă ÷ număr). Mediana este valoarea din mijloc atunci când este sortată. Modul este valoarea care apare cel mai frecvent. Toate pot diferi, mai ales cu date asimetrice sau valori aberante.

De ce aș folosi mediana în loc de medie?

Mediana este mai rezistentă la valorile aberante - o singură valoare extremă poate trage media departe de unde se află efectiv majoritatea datelor, în timp ce mediana rămâne ancorată la mijlocul datelor sortate, indiferent de cât de extreme sunt valorile aberante.

Poate un set de date să aibă mai mult de un mod?

Da - dacă două sau mai multe valori sunt la egalitate pentru cea mai mare frecvență, setul de date este "multimodal" și toate sunt raportate ca moduri. Dacă fiecare valoare apare exact o dată, nu există un mod semnificativ.

Ce îți spune amplitudinea pe care media sau mediana nu ți-o spun?

Amplitudinea măsoară dispersia datelor (maxim minus minim), în timp ce media și mediana îi descriu centrul - două seturi de date pot avea medii identice dar amplitudini foarte diferite, reflectând cantități foarte diferite de variabilitate.
