Comparație JSON

Lipește două obiecte JSON pentru a vedea o comparație câmp cu câmp - ce a fost adăugat, eliminat, sau schimbat între ele.

Ultima actualizare: September 5, 2026

Întrebări frecvente

Cum funcționează acest instrument de comparație JSON?

Analizează ambele obiecte JSON, apoi parcurge recursiv fiecare cheie: cheile prezente doar în primul sunt marcate "Eliminat", cheile prezente doar în al doilea sunt marcate "Adăugat", iar cheile prezente în ambele cu valori diferite sunt marcate "Schimbat". Obiectele imbricate sunt comparate câmp cu câmp, nu ca un singur bloc mare.

Aceasta compară array-urile element cu element?

Array-urile sunt comparate după valoarea exactă (întregul array este tratat ca "schimbat" dacă orice element diferă), nu îmbinate element cu element ca obiectele - acest lucru menține logica de comparație previzibilă pentru array-urile unde ordinea contează.

Ce se întâmplă dacă JSON-ul meu are o eroare de sintaxă?

Acest instrument raportează care dintre cele două intrări JSON este invalidă, împreună cu mesajul de eroare al parserului, în loc să încerce o comparație parțială sau ghicită - corectează mai întâi eroarea de sintaxă, apoi compară.
