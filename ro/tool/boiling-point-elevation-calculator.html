Calculator de Creștere a Punctului de Fierbere

Introdu molalitatea, factorul van 't Hoff și solventul (sau o constantă ebulioscopică Kb personalizată) pentru a afla creșterea punctului de fierbere. Opțional, obții punctul de fierbere estimat al soluției. Ecuația este un model idealizat de soluție diluată.

Ultima actualizare: September 26, 2026

Întrebări frecvente

Ce este creșterea punctului de fierbere?

Este creșterea temperaturii de fierbere a unui solvent atunci când în el se dizolvă un solut nevolatil. Particulele dizolvate scad presiunea de vapori a solventului, deci este nevoie de o temperatură mai mare pentru a fierbe.

Care este formula?

ΔTb = i × Kb × m, unde i este factorul van 't Hoff, Kb este constanta ebulioscopică a solventului în K·kg/mol, iar m este molalitatea în mol/kg.

Care este diferența dintre molalitate și molaritate?

Molalitatea este numărul de moli de solut pe kilogram de solvent. Molaritatea este numărul de moli pe litru de soluție. Ecuația folosește molalitatea.

Ce factor van 't Hoff să folosesc?

Este aproximativ 1 pentru molecule care nu se disociază, precum zahărul, și aproape 2 pentru o sare complet disociată precum NaCl. Soluțiile reale se abat de la aceste valori ideale.

De ce este Kb diferită pentru fiecare solvent?

Kb depinde de proprietățile solventului. De aceea calculatorul oferă solvenți presetați și o opțiune personalizată în loc de o singură constantă pentru toate.

Când eșuează ecuația?

Pentru soluții concentrate, cu interacțiuni puternice sau cu soluți volatili. Este un model idealizat de soluție diluată.
