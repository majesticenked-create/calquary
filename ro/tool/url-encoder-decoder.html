Codificator / Decodificator URL

Introdu text sau un șir codificat URL, alege o direcție, și obține instant rezultatul codificat sau decodificat.

Ultima actualizare: September 1, 2026

Întrebări frecvente

Ce face codificarea URL?

Convertește caracterele care nu sunt sigure într-un URL (spații, &, ?, #, și altele) într-un semn procent urmat de codul lor hex - de exemplu, un spațiu devine %20 - astfel încât textul să poată fi inclus în siguranță într-un URL, precum o interogare de căutare sau valoare de parametru.

De ce un spațiu devine %20 în loc de un semn plus (+)?

Ambele sunt folosite în practică: %20 este codificarea procent standard pentru un spațiu oriunde într-un URL, în timp ce + înseamnă specific "spațiu" doar în șirurile de interogare URL (date codificate de formular), o convenție moștenită din formularele HTML. Acest instrument folosește %20, codificarea mai corectă universal.

Ce se întâmplă dacă încerc să decodific text care nu este de fapt codificat?

Textul simplu fără secvențe % este decodificat înapoi la sine neschimbat, deoarece nu este nimic de convertit - decodificarea eșuează doar dacă textul conține o secvență % incompletă sau invalidă (precum un % neurmat de două cifre hex valide).

Este aceasta la fel cu encodeURIComponent() din JavaScript?

Da - codificarea folosește exact acea funcție, care este modul standard de a codifica în siguranță o singură valoare (precum un parametru de interogare) pentru utilizare într-un URL, spre deosebire de encodeURI() care este menită pentru codificarea unui URL întreg și lasă neatinse caractere precum / și :.
