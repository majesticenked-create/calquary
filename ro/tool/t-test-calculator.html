Calculator Test T

Introdu media, deviația standard, și dimensiunea eșantionului fiecărui grup pentru a calcula statistica t și gradele de libertate.

Ultima actualizare: September 1, 2026

Întrebări frecvente

Ce îmi spune statistica t?

Măsoară câte erori standard separă mediile celor două grupuri - cu cât |t| este mai mare, cu atât este mai puțin probabil ca diferența dintre grupuri să se fi întâmplat doar din întâmplare, presupunând că ipoteza nulă (fără diferență reală) este adevărată.

Cum știu dacă rezultatul meu este semnificativ statistic?

Compară |t| calculat cu o valoare critică dintr-un tabel de distribuție t, folosind gradele tale de libertate și nivelul de semnificație ales (de obicei 0,05) - dacă |t| depășește valoarea critică, rezultatul este semnificativ la acel nivel.

Care este diferența dintre acesta și un test t pereche?

Acest calculator presupune două grupuri independente (precum un grup de tratament vs. un grup de control de persoane diferite). Un test t pereche compară în schimb două măsurători pe aceiași subiecți (precum înainte/după) - pentru asta, calculează media și deviația standard a diferențelor, apoi tratează-l ca un test t cu un eșantion față de zero.

De ce se folosește deviația standard "combinată"?

Combinarea unește varianța ambelor grupuri într-o singură estimare ponderată, care este abordarea standard atunci când poți presupune în mod rezonabil că ambele grupuri au varianță de bază similară - folosește mai mult din datele tale decât bazarea doar pe varianța unui singur grup.
