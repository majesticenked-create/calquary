Calculator de Valori și Vectori Proprii (2x2)

Introdu cele patru intrări ale unei matrice 2x2 [[a, b], [c, d]] pentru a calcula valorile și vectorii proprii.

Ultima actualizare: September 5, 2026

Întrebări frecvente

Cum găsesc valorile proprii ale unei matrice 2x2?

Rezolvă det(A − λI) = 0, care pentru o matrice 2x2 [[a,b],[c,d]] se simplifică la λ² − (a+d)λ + (ad−bc) = 0 - o ecuație pătratică în λ, folosind urma matricei (a+d) și determinantul (ad−bc). Acest calculator aplică direct acea formulă.

Cum găsesc vectorul propriu odată ce am o valoare proprie?

Rezolvă (A − λI)v = 0 pentru vectorul v - pentru o matrice 2x2 aceasta se reduce la o ecuație independentă, deoarece sistemul este singular prin construcție. Acest calculator rezolvă direct asta din intrarea b sau c și valoarea proprie.

Ce înseamnă dacă valorile proprii sunt complexe?

Valorile proprii complexe înseamnă că matricea nu are vectori proprii reali - geometric, acest lucru se întâmplă pentru matrici care rotesc vectori (precum o matrice de rotație) mai degrabă decât să îi întindă pur și simplu de-a lungul direcțiilor fixe, deoarece o rotație nu are nicio direcție care rămâne neschimbată (cu excepția unei rotații de 180°).

Ce reprezintă valorile proprii și vectorii proprii în lumea reală?

Descriu direcțiile pe care o transformare matriceală nu le rotește, ci doar le întinde sau le comprimă - vectorul propriu este acea direcție neschimbată, iar valoarea proprie este factorul de întindere. Acest lucru apare în aplicații precum analiza vibrațiilor, analiza componentelor principale și algoritmul PageRank al Google.

Care sunt valorile proprii ale matricei [[2,1],[1,2]]?

3 și 1 - urma = 2+2 = 4, determinant = (2×2)-(1×1) = 3, deci λ² − 4λ + 3 = 0 se factorizează ca (λ−3)(λ−1) = 0, dând λ = 3 și λ = 1.

Poate o matrice 2x2 să aibă o singură valoare proprie?

Da - acest lucru se întâmplă atunci când discriminantul ecuației caracteristice este zero (o valoare proprie "repetată" sau "degenerată"), ceea ce apare pentru matrici precum [[2,1],[0,2]], unde ambele rădăcini ale ecuației pătratice coincid la aceeași valoare.
