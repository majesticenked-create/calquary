Frequently asked questions

What is the coupon collector's problem?

A classic probability problem: if there are n distinct items and each random draw is equally likely to be any one of them (with replacement), how many draws on average does it take to collect at least one of every item?

What's the expected number of draws to collect all 6 items?

About 14.7 draws - using expected draws = n × Hₙ = 6 × (1 + 1/2 + 1/3 + 1/4 + 1/5 + 1/6) = 6 × 2.45 ≈ 14.7.

Why does it get disproportionately harder to collect the last few items?

Early draws are likely to be new items since most of the set is still uncollected, but as you collect more, each new draw has a shrinking chance of being one of the few remaining types - the last item alone takes n draws on average to find.

Does this assume every item is equally likely to be drawn?

Yes - this calculation assumes a uniform distribution, where each of the n items has an equal 1/n chance on every draw. If some items are rarer than others, the actual expected number of draws will be higher than this estimate.
