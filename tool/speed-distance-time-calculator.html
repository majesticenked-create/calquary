Frequently asked questions

What's the formula connecting speed, distance, and time?

Speed = distance ÷ time. Rearranged, distance = speed × time, and time = distance ÷ speed - all three formulas describe the same relationship, just solved for a different variable.

How do I calculate speed if I know distance and time?

Divide distance by time. A trip covering 120 miles in 2 hours averages 120 ÷ 2 = 60 mph.

Do the units need to match, like miles and hours?

Yes - this calculator doesn't convert units, so make sure distance and speed use the same unit (both miles or both km) and time is in hours to get a correctly-scaled result. Use the unit length converter first if your distance is in a different unit than your speed.

Is 'speed distance time converter,' 'time calculator for speed and distance,' and 'distance calculator from speed and time' all the same as this tool?

Yes - every one of these phrasings describes the same three-way relationship (speed = distance ÷ time), just naming a different variable first. Choose what you're solving for above and enter the other two values.
