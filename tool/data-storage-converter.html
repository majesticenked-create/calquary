Frequently asked questions

How many MB is a GB?

1 GB equals 1,024 MB using the binary convention this calculator uses (1 KB = 1,024 bytes) - this is standard for computing contexts like file sizes and RAM.

Why do storage sizes sometimes not match what I expect?

Storage manufacturers often use decimal units (1 GB = 1,000 MB) for marketing, while operating systems typically report binary units (1 GB = 1,024 MB) - this is why a "1 TB" drive shows less space than expected in your file explorer.

Why do hard drive capacities sometimes show less space than advertised?

Manufacturers typically calculate storage using decimal units (1 GB = 1,000,000,000 bytes), while operating systems often display capacity using binary units (1 GB = 1,073,741,824 bytes) - the same physical drive shows a smaller number under the binary convention, which is why advertised and displayed capacities don't always match.

What's the difference between a megabyte (MB) and a mebibyte (MiB)?

A megabyte is typically 1,000 kilobytes (decimal, base-10), used by storage manufacturers, while a mebibyte is 1,024 kibibytes (binary, base-2), used by most operating systems when reporting file and disk sizes - this mismatch is why a '256GB' drive often shows less usable space in your OS.

How many bytes are in a kilobyte?

1,024 bytes, using the binary convention (2^10) this calculator applies - not 1,000, which is the decimal convention some manufacturers use for marketing storage capacity.

How do I convert gigabytes to terabytes?

Divide by 1,024. 2,048 GB ÷ 1,024 = 2 TB, using this calculator's binary convention.

Is 'GB to MB converter' the same tool as this data storage converter?

Yes - GB-to-MB is just one of the many byte-unit conversions (bytes, KB, MB, GB, TB) this single converter handles.
