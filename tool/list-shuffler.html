List Shuffler

Paste a list of items (one per line) to shuffle them into random order.

Last updated: September 5, 2026

Frequently asked questions

How random is this shuffle?

It uses the Fisher-Yates shuffle algorithm with your browser's random number generator, which gives every possible ordering an equal chance - a well-established, unbiased shuffling method.

Does this remove duplicate items from my list?

No - it only reorders the list you enter. If your list has duplicates, they stay in the shuffled output; remove them from your input first if you don't want repeats.

How is this different from the Group Randomizer?

This tool just reorders a single list. The Group Randomizer instead splits a list of names into a set number of teams or groups - use that one if you need to divide people up, not just reorder them.

Can I use this to randomize the order of a playlist, raffle entries, or presentation order?

Yes - paste any list (songs, names, topics) one per line, and it works for any of those use cases the same way.

Will shuffling the same list twice give the same result?

No - each shuffle draws fresh random values, so running the tool again on the same input list produces a new, independent random order each time.

If I shuffle a 5-item list, how many possible orders are there?

120 (5 factorial: 5×4×3×2×1). Fisher-Yates gives each of those 120 orderings an equal chance of being the result.

Is this the same as a 'randomize order' or 'randomize list' tool?

Yes - 'list shuffler,' 'randomize list order,' and 'random list sorter' all describe the same task: taking a list and outputting it in a random sequence, which is exactly what this tool does.
