Shuffled Deck of Cards

Choose how many cards to draw from a freshly shuffled standard 52-card deck.

Last updated: August 30, 2026

Frequently asked questions

How is this deck shuffled?

Using a Fisher-Yates shuffle - a well-established algorithm that gives every one of the 52! (about 8×10^67) possible orderings an equal chance, run using your browser's random number generator.

Can I draw fewer than 52 cards, like for a poker hand?

Yes - set "cards to draw" to however many you need (5 for a poker hand, 13 for a bridge hand, etc.) and this pulls that many cards from the top of a freshly shuffled deck.

Does this include jokers?

No - this is a standard 52-card deck (4 suits × 13 ranks, no jokers), which matches the deck used in most card games. Jokers aren't part of the standard deck this tool shuffles.
