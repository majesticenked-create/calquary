Frequently asked questions

How is text converted to binary?

Each character's numeric code (from the ASCII/Unicode table) is converted to base-2 and padded to 8 bits - 'H' has code 72, which is 01001000 in binary.

Why 8 bits per character?

8 bits (1 byte) covers the standard ASCII character set (0-255), which includes all English letters, numbers, and common symbols.

What happens if I enter a binary string that isn't a multiple of 8 bits?

Standard text encoding (ASCII/UTF-8) represents each character as a full 8-bit byte, so a binary string that isn't a clean multiple of 8 bits can't be converted to valid characters and will likely produce an error or unexpected result - double-check your binary input is grouped correctly.

Can this convert binary to numbers as well as text?

This tool converts binary directly to readable text using standard 8-bit character encoding (ASCII/UTF-8). To convert binary to a plain numeric value instead, treat the binary string as a base-2 number and convert it to base-10 using a binary-to-decimal calculation instead.
