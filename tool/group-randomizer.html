Group Randomizer

Enter one name per line and choose how many groups to split them into - each group is randomly and evenly assigned.

Last updated: August 30, 2026

Frequently asked questions

How does this randomize groups fairly?

It uses a Fisher-Yates shuffle - a well-established algorithm that gives every name an equal, unbiased chance of ending up in any position - then deals the shuffled list into groups in round-robin order, which keeps group sizes as even as possible.

What happens if the number of people doesn't divide evenly into groups?

The extra people are spread one-per-group starting from the first group, so group sizes differ by at most one person - for 10 people split into 3 groups, you'll get groups of 4, 3, and 3, not 4, 4, and 2.

Can I use this for classroom teams or a work project split?

Yes - this works for any scenario where you need an unbiased random split of a list of names into a fixed number of groups, whether that's classroom project teams, sports teams, or dividing up a task list at work.

Can I use this as a randomizer to pick one random winner or order names randomly?

Yes - set the number of groups to 1, and this calculator shuffles your entire list into a single random order (the fairest way to pick a random winner is to take whoever ends up first). Every reshuffle uses a fresh Fisher-Yates shuffle.

Is a 'randomizer list' or 'random a list' the same as this tool?

Yes - both describe shuffling a list into random order, which this tool does (set groups to 1 for a single shuffled list, or more for random group splits).

Is 'random draws,' 'random list creator,' or 'list random generator' different from this tool?

No - all of these describe randomly ordering or drawing from a list, which this calculator does. Set groups to 1 to shuffle the whole list into random order.

Is 'random generator for teams' or 'randomize list' different from this tool?

No - both describe splitting or shuffling a list of names randomly, which is exactly what this calculator does. Set the number of groups to however many teams you need, or to 1 to just shuffle the whole list.
