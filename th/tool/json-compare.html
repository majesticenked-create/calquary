เปรียบเทียบ JSON

วางออบเจ็กต์ JSON สองรายการเพื่อดูความแตกต่างทีละฟิลด์ - สิ่งที่เพิ่ม ลบ หรือเปลี่ยนแปลงระหว่างทั้งสอง

อัปเดตล่าสุด: September 5, 2026

คำถามที่พบบ่อย

เครื่องมือเปรียบเทียบ JSON นี้ทำงานอย่างไร?

มันแยกวิเคราะห์ออบเจ็กต์ JSON ทั้งสอง จากนั้นเดินผ่านทุกคีย์แบบเรียกซ้ำ: คีย์ที่มีเฉพาะในรายการแรกจะถูกทำเครื่องหมายว่า "ลบแล้ว" คีย์ที่มีเฉพาะในรายการที่สองจะถูกทำเครื่องหมายว่า "เพิ่มแล้ว" และคีย์ที่มีอยู่ในทั้งสองแต่มีค่าต่างกันจะถูกทำเครื่องหมายว่า "เปลี่ยนแปลงแล้ว" ออบเจ็กต์ที่ซ้อนกันจะถูกเปรียบเทียบทีละฟิลด์ ไม่ใช่เป็นก้อนใหญ่ก้อนเดียว

สิ่งนี้เปรียบเทียบอาร์เรย์ทีละองค์ประกอบหรือไม่?

อาร์เรย์ถูกเปรียบเทียบด้วยค่าที่แน่นอน (อาร์เรย์ทั้งหมดถือว่า "เปลี่ยนแปลง" หากองค์ประกอบใดแตกต่างกัน) ไม่ได้รวมทีละองค์ประกอบเหมือนออบเจ็กต์ - สิ่งนี้ทำให้ตรรกะความแตกต่างสามารถคาดเดาได้สำหรับอาร์เรย์ที่ลำดับมีความสำคัญ

จะเกิดอะไรขึ้นถ้า JSON ของฉันมีข้อผิดพลาดทางไวยากรณ์?

เครื่องมือนี้รายงานว่าอินพุต JSON ใดในสองรายการไม่ถูกต้อง พร้อมข้อความแสดงข้อผิดพลาดของตัวแยกวิเคราะห์ แทนที่จะพยายามเปรียบเทียบบางส่วนหรือคาดเดา - แก้ไขข้อผิดพลาดทางไวยากรณ์ก่อน จากนั้นจึงเปรียบเทียบ

เครื่องมือที่เกี่ยวข้อง

    หมายเหตุเกี่ยวกับความแม่นยำ

    เครื่องคำนวณของ Calquary ออกแบบมาเพื่อให้การประมาณค่าที่รวดเร็วและเชื่อถือได้ สำหรับการตัดสินใจที่มีผลกระทบทางการเงิน โครงสร้าง หรือทางการแพทย์อย่างแท้จริง โปรดปรึกษาผู้เชี่ยวชาญที่มีคุณสมบัติเหมาะสม
