ตัวเข้ารหัส / ถอดรหัส URL

ป้อนข้อความหรือสตริงที่เข้ารหัส URL เลือกทิศทาง และรับผลลัพธ์ที่เข้ารหัสหรือถอดรหัสได้ทันที

อัปเดตล่าสุด: September 1, 2026

คำถามที่พบบ่อย

การเข้ารหัส URL ทำอะไร?

แปลงอักขระที่ไม่ปลอดภัยใน URL (เว้นวรรค, &, ?, # และอื่นๆ) เป็นเครื่องหมายเปอร์เซ็นต์ตามด้วยรหัสเลขฐานสิบหก - ตัวอย่างเช่น เว้นวรรคจะกลายเป็น %20 - เพื่อให้ข้อความสามารถรวมอยู่ใน URL ได้อย่างปลอดภัย เช่น คำค้นหาหรือค่าพารามิเตอร์

ทำไมเว้นวรรคถึงกลายเป็น %20 แทนที่จะเป็นเครื่องหมายบวก (+)?

ทั้งสองแบบใช้ในทางปฏิบัติ: %20 คือการเข้ารหัสเปอร์เซ็นต์มาตรฐานสำหรับเว้นวรรคทุกที่ใน URL ในขณะที่ + หมายถึง "เว้นวรรค" เฉพาะภายในสตริงคำค้นหา URL (ข้อมูลที่เข้ารหัสแบบฟอร์ม) เท่านั้น ซึ่งเป็นธรรมเนียมเก่าจากฟอร์ม HTML เครื่องมือนี้ใช้ %20 ซึ่งเป็นการเข้ารหัสที่ถูกต้องเป็นสากลมากกว่า

จะเกิดอะไรขึ้นถ้าฉันพยายามถอดรหัสข้อความที่ไม่ได้เข้ารหัสจริงๆ?

ข้อความธรรมดาที่ไม่มีลำดับ % จะถูกถอดรหัสกลับเป็นตัวมันเองโดยไม่เปลี่ยนแปลง เนื่องจากไม่มีอะไรต้องแปลง - การถอดรหัสจะล้มเหลวก็ต่อเมื่อข้อความมีลำดับ % ที่ไม่สมบูรณ์หรือไม่ถูกต้อง (เช่น % ที่ไม่ตามด้วยเลขฐานสิบหกที่ถูกต้องสองตัว)

นี่เหมือนกับ encodeURIComponent() ใน JavaScript หรือไม่?

ใช่ - การเข้ารหัสใช้ฟังก์ชันนั้นโดยตรง ซึ่งเป็นวิธีมาตรฐานในการเข้ารหัสค่าเดียว (เช่น พารามิเตอร์คำค้นหา) อย่างปลอดภัยเพื่อใช้ใน URL ตรงข้ามกับ encodeURI() ซึ่งมีไว้สำหรับเข้ารหัส URL ทั้งหมดและปล่อยให้อักขระเช่น / และ : ไม่เปลี่ยนแปลง
