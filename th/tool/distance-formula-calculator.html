Calquary / คณิตศาสตร์

เครื่องคำนวณสูตรระยะทาง

ป้อนพิกัดของสองจุดเพื่อคำนวณระยะทางเส้นตรงและจุดกึ่งกลางระหว่างจุดทั้งสอง

อัปเดตล่าสุด: September 5, 2026

คำถามที่พบบ่อย

สูตรระยะทางคืออะไร?

d = √((x₂-x₁)² + (y₂-y₁)²) - หาระยะทางเส้นตรงระหว่างสองจุด (x₁,y₁) และ (x₂,y₂) บนระนาบพิกัด

สูตรระยะทางเกี่ยวข้องกับทฤษฎีบทพีทาโกรัสอย่างไร?

เป็นทฤษฎีบทเดียวกันที่นำไปใช้กับพิกัด - ผลต่างแนวนอน (Δx) และผลต่างแนวตั้ง (Δy) ระหว่างสองจุดสร้างด้านประกอบมุมฉากสองด้านของสามเหลี่ยมมุมฉาก และระยะทางระหว่างจุดทั้งสองคือด้านตรงข้ามมุมฉาก

ระยะทางระหว่าง (1,2) และ (4,6) คือเท่าไหร่?

5 - Δx = 4-1 = 3, Δy = 6-2 = 4 ดังนั้น d = √(3² + 4²) = √(9+16) = √25 = 5

ฉันจะหาจุดกึ่งกลางระหว่างสองจุดได้อย่างไร?

หาค่าเฉลี่ยของพิกัด x และค่าเฉลี่ยของพิกัด y แยกกัน: จุดกึ่งกลาง = ((x₁+x₂)/2, (y₁+y₂)/2) สำหรับ (1,2) และ (4,6) จุดกึ่งกลางคือ (2.5, 4)

เครื่องมือที่เกี่ยวข้อง

    หมายเหตุเกี่ยวกับความแม่นยำ

    เครื่องคำนวณของ Calquary ออกแบบมาเพื่อให้การประมาณค่าที่รวดเร็วและเชื่อถือได้ สำหรับการตัดสินใจที่มีผลกระทบทางการเงิน โครงสร้าง หรือทางการแพทย์อย่างแท้จริง โปรดปรึกษาผู้เชี่ยวชาญที่มีคุณสมบัติเหมาะสม
