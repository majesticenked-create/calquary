คำถามที่พบบ่อย

ฉันจะแก้สมการเชิงเส้นเช่น 3x + 5 = 20 ได้อย่างไร?

แยก x ออกมา: ลบ 5 ออกจากทั้งสองข้างเพื่อได้ 3x = 15 จากนั้นหารทั้งสองข้างด้วย 3 เพื่อได้ x = 5 โดยทั่วไป สำหรับ ax + b = c, x = (c − b) / a

ถ้าสมการมี x ทั้งสองข้าง เช่น 2x + 3 = x + 10 ล่ะ?

ย้ายพจน์ x ทั้งหมดไปด้านหนึ่งและค่าคงที่ไปอีกด้านก่อน: การลบ x ออกจากทั้งสองข้างจะได้ x + 3 = 10 จากนั้นลบ 3 จะได้ x = 7 จัดเรียงสมการของคุณให้อยู่ในรูปแบบ ax + b = c ก่อนป้อนที่นี่

ถ้า a = 0 ในเครื่องคำนวณนี้หมายความว่าอย่างไร?

ถ้า a เป็น 0 ก็ไม่มีพจน์ x เหลือให้แก้ - สมการจะกลายเป็นเพียง b = c ถ้าเป็นจริง (เช่น 5 = 5) ค่า x ทุกค่าจะสอดคล้อง ถ้าเป็นเท็จ (เช่น 5 = 7) ไม่มีค่า x ใดที่จะสอดคล้องได้ เนื่องจากพจน์ x ไม่สามารถเปลี่ยนผลลัพธ์ได้
