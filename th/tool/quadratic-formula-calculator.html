เครื่องคำนวณสูตรกำลังสอง

ป้อนสัมประสิทธิ์ a, b และ c เพื่อแก้สมการกำลังสองสำหรับ x รวมถึงรากเชิงซ้อนเมื่อจำเป็น

อัปเดตล่าสุด: August 30, 2026

คำถามที่พบบ่อย

ฉันจะแก้ x² − 3x + 2 = 0 ได้อย่างไร?

ใช้สูตรกำลังสองด้วย a=1, b=−3, c=2: ดิสคริมิแนนต์คือ 9 − 8 = 1 ให้รากจริงสองค่า x = 2 และ x = 1

ดิสคริมิแนนต์ที่เป็นลบหมายความว่าอย่างไร?

ดิสคริมิแนนต์ที่เป็นลบหมายความว่าสมการไม่มีคำตอบจริง - รากเป็นจำนวนเชิงซ้อน เนื่องจากคุณจะต้องหารากที่สองของจำนวนลบ

ถ้าสมการกำลังสองไม่มีคำตอบจริงจะเกิดอะไรขึ้น?

สิ่งนี้เกิดขึ้นเมื่อดิสคริมิแนนต์ (b² − 4ac) เป็นลบ - สมการยังคงมีสองคำตอบ แต่เป็นจำนวนเชิงซ้อนที่เกี่ยวข้องกับหน่วยจินตภาพ i เนื่องจากคุณไม่สามารถหารากที่สองของจำนวนลบภายในจำนวนจริงได้

ความแตกต่างระหว่างสูตรกำลังสองและการแยกตัวประกอบคืออะไร?

การแยกตัวประกอบจะได้ผลดีเฉพาะเมื่อสมการกำลังสองมีรากที่เรียบง่าย มักเป็นจำนวนเต็ม สูตรกำลังสองจะได้ผลเสมอ สำหรับสมการกำลังสองใดๆ ไม่ว่ารากจะเป็นจำนวนเต็ม เศษส่วน ทศนิยม หรือจำนวนเชิงซ้อน เครื่องคำนวณนี้ใช้สูตรโดยตรง จึงจัดการทุกกรณีโดยไม่ต้องเดาตัวประกอบก่อน

"เครื่องคำนวณสูตรสมการกำลังสอง" "แก้เครื่องคำนวณสูตรกำลังสอง" และ "เครื่องคำนวณสำหรับแก้สมการกำลังสอง" เหมือนกับเครื่องมือนี้หรือไม่?

ใช่ - แต่ละชื่อเหล่านี้อธิบายการแก้ ax² + bx + c = 0 สำหรับ x ซึ่งเป็นสิ่งที่เครื่องคำนวณนี้ทำอย่างแม่นยำ ป้อนสัมประสิทธิ์ a, b และ c ของคุณด้านบน และมันจะใช้สูตรกำลังสองโดยอัตโนมัติ รวมถึงรากจริงหรือรากเชิงซ้อน

สิ่งนี้แสดงขั้นตอนเหมือน "ตัวแก้คณิตศาสตร์พร้อมขั้นตอน" หรือไม่?

ใช่ - เลื่อนดูตารางด้านล่างผลลัพธ์เพื่อดูงานทีละขั้นตอนแบบเต็ม: ระบุ a, b, c คำนวณดิสคริมิแนนต์ หารากที่สอง และแก้หา x

เครื่องมือที่เกี่ยวข้อง

    หมายเหตุเกี่ยวกับความแม่นยำ

    เครื่องคำนวณของ Calquary ออกแบบมาเพื่อให้การประมาณค่าที่รวดเร็วและเชื่อถือได้ สำหรับการตัดสินใจที่มีผลกระทบทางการเงิน โครงสร้าง หรือทางการแพทย์อย่างแท้จริง โปรดปรึกษาผู้เชี่ยวชาญที่มีคุณสมบัติเหมาะสม
