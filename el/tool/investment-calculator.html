Αριθμομηχανή Επένδυσης

Εισάγετε την αρχική επένδυση, τη μηνιαία συνεισφορά, την αναμενόμενη απόδοση και τον πληθωρισμό για να δείτε τόσο την ονομαστική όσο και την προσαρμοσμένη στον πληθωρισμό μελλοντική αξία.

Τελευταία ενημέρωση: August 30, 2026

Συχνές ερωτήσεις

Γιατί ο πληθωρισμός έχει σημασία για τις προβλέψεις επενδύσεων;

Ένα δολάριο σε 20 χρόνια αγοράζει λιγότερα από ένα δολάριο σήμερα - η εμφάνιση μόνο της ονομαστικής μελλοντικής αξίας υπερβάλλει πόσο καλύτερα θα είστε πραγματικά, οπότε η προσαρμογή για πληθωρισμό δίνει μια πιο ειλικρινή εικόνα.

Ποιο ποσοστό απόδοσης πρέπει να χρησιμοποιήσω για μια αριθμομηχανή επένδυσης;

Το 7% είναι ένας συνήθως χρησιμοποιούμενος μακροπρόθεσμος μέσος όρος για ένα διαφοροποιημένο χαρτοφυλάκιο μετοχών αφού ο πληθωρισμός έχει ληφθεί περίπου υπόψη σε ονομαστικούς όρους, αλλά οι πραγματικές αποδόσεις διαφέρουν σημαντικά από έτος σε έτος - χρησιμοποιήστε μια συντηρητική εκτίμηση για τον σχεδιασμό.

Πώς επηρεάζει η συχνότητα συνεισφοράς τη μακροπρόθεσμη ανάπτυξη;

Οι πιο συχνές συνεισφορές (μηνιαία αντί ετησίως) επιτρέπουν στα χρήματά σας να αρχίσουν να ανατοκίζονται νωρίτερα κατά μέσο όρο, κάτι που παράγει ένα μέτρια υψηλότερο τελικό υπόλοιπο για το ίδιο συνολικό ποσό που συνεισφέρθηκε στην ίδια περίοδο.

Ποια είναι μια ρεαλιστική μέση ετήσια απόδοση που πρέπει να υποθέσουμε για μακροπρόθεσμες προβλέψεις;

Ιστορικά, τα διαφοροποιημένα αμοιβαία κεφάλαια δεικτών χρηματιστηρίου είχαν κατά μέσο όρο περίπου 7-10% ετήσιες αποδόσεις πριν τον πληθωρισμό σε περιόδους πολλών δεκαετιών, αν και ένα μεμονωμένο έτος μπορεί να διαφέρει σημαντικά. Η χρήση μιας πιο συντηρητικής εκτίμησης (6-7%) για σκοπούς σχεδιασμού λαμβάνει υπόψη καλύτερα τη μεταβλητότητα και τα τέλη από το να υποθέτουμε έναν μέσο όρο βέλτιστης περίπτωσης κάθε χρόνο.
