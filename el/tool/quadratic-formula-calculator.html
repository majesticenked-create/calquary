Υπολογιστής Δευτεροβάθμιας Εξίσωσης

Εισάγετε τους συντελεστές a, b, και c για να λύσετε μια δευτεροβάθμια εξίσωση ως προς x, συμπεριλαμβανομένων μιγαδικών ριζών όταν χρειάζεται.

Τελευταία ενημέρωση: August 30, 2026

Συχνές ερωτήσεις

Πώς λύνω το x² − 3x + 2 = 0;

Χρησιμοποιώντας τη δευτεροβάθμια εξίσωση με a=1, b=−3, c=2: η διακρίνουσα είναι 9 − 8 = 1, δίνοντας δύο πραγματικές ρίζες x = 2 και x = 1.

Τι σημαίνει αρνητική διακρίνουσα;

Μια αρνητική διακρίνουσα σημαίνει ότι η εξίσωση δεν έχει πραγματικές λύσεις - οι ρίζες είναι μιγαδικοί αριθμοί, αφού θα χρειαζόσασταν την τετραγωνική ρίζα ενός αρνητικού αριθμού.

Τι γίνεται αν μια δευτεροβάθμια εξίσωση δεν έχει πραγματικές λύσεις;

Αυτό συμβαίνει όταν η διακρίνουσα (b² − 4ac) είναι αρνητική - η εξίσωση εξακολουθεί να έχει δύο λύσεις, αλλά είναι μιγαδικοί αριθμοί που περιλαμβάνουν τη φανταστική μονάδα i, αφού δεν μπορείτε να πάρετε την τετραγωνική ρίζα ενός αρνητικού αριθμού στους πραγματικούς αριθμούς.

Ποια είναι η διαφορά μεταξύ της δευτεροβάθμιας εξίσωσης και της παραγοντοποίησης;

Η παραγοντοποίηση λειτουργεί καθαρά μόνο όταν μια δευτεροβάθμια έχει απλές, συχνά ακέραιες ρίζες· η δευτεροβάθμια εξίσωση λειτουργεί πάντα, για οποιαδήποτε δευτεροβάθμια εξίσωση, είτε οι ρίζες είναι ακέραιοι αριθμοί, κλάσματα, δεκαδικοί, ή μιγαδικοί αριθμοί. Αυτή η αριθμομηχανή χρησιμοποιεί απευθείας τον τύπο, οπότε χειρίζεται κάθε περίπτωση χωρίς να χρειάζεται να μαντέψει παράγοντες πρώτα.

Είναι ένας «υπολογιστής τύπου δευτεροβάθμιας εξίσωσης», «λύσε υπολογιστή δευτεροβάθμιου τύπου», και «υπολογιστής για την επίλυση δευτεροβάθμιων εξισώσεων» το ίδιο με αυτό το εργαλείο;

Ναι - καθένα από αυτά τα ονόματα περιγράφει την επίλυση του ax² + bx + c = 0 ως προς x, που είναι ακριβώς αυτό που κάνει αυτή η αριθμομηχανή. Εισάγετε τους συντελεστές σας a, b, και c παραπάνω και εφαρμόζει αυτόματα τη δευτεροβάθμια εξίσωση, πραγματικές ή μιγαδικές ρίζες συμπεριλαμβανομένες.

Δείχνει αυτό τα βήματα, όπως ένας «μαθηματικός επιλυτής με βήματα»;

Ναι - κάντε κύλιση στον πίνακα κάτω από το αποτέλεσμα για την πλήρη βήμα προς βήμα εργασία: προσδιορισμός a, b, c, υπολογισμός της διακρίνουσας, λήψη της τετραγωνικής ρίζας, και επίλυση ως προς x.
