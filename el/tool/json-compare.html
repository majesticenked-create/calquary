Σύγκριση JSON

Επικολλήστε δύο αντικείμενα JSON για να δείτε μια σύγκριση πεδίο προς πεδίο - τι προστέθηκε, αφαιρέθηκε, ή άλλαξε μεταξύ τους.

Τελευταία ενημέρωση: August 30, 2026

Συχνές ερωτήσεις

Πώς λειτουργεί αυτό το εργαλείο σύγκρισης JSON;

Αναλύει και τα δύο αντικείμενα JSON, στη συνέχεια διατρέχει αναδρομικά κάθε κλειδί: τα κλειδιά μόνο στο πρώτο επισημαίνονται ως «Αφαιρέθηκε», τα κλειδιά μόνο στο δεύτερο επισημαίνονται ως «Προστέθηκε», και τα κλειδιά που υπάρχουν και στα δύο με διαφορετικές τιμές επισημαίνονται ως «Άλλαξε». Τα εμφωλευμένα αντικείμενα συγκρίνονται πεδίο προς πεδίο, όχι ως ένα μεγάλο ενιαίο τμήμα.

Συγκρίνει αυτό τους πίνακες στοιχείο προς στοιχείο;

Οι πίνακες συγκρίνονται με ακριβή τιμή (ολόκληρος ο πίνακας αντιμετωπίζεται ως «άλλαξε» αν οποιοδήποτε στοιχείο διαφέρει), δεν συγχωνεύονται στοιχείο προς στοιχείο όπως τα αντικείμενα - αυτό διατηρεί τη λογική σύγκρισης προβλέψιμη για πίνακες όπου η σειρά έχει σημασία.

Τι συμβαίνει αν το JSON μου έχει σφάλμα σύνταξης;

Αυτό το εργαλείο αναφέρει ποια από τις δύο εισόδους JSON είναι μη έγκυρη, μαζί με το μήνυμα σφάλματος του αναλυτή, αντί να επιχειρήσει μια μερική ή εικαστική σύγκριση - διορθώστε πρώτα το σφάλμα σύνταξης, στη συνέχεια συγκρίνετε.
