常见问题

如何把华氏度换算成摄氏度？

先减去32，再乘以5/9。以98.6°F为例：(98.6 − 32) × 5/9 = 37°C（人体的正常体温）。

为什么温度换算需要平移，而不仅仅是乘法？

华氏度和摄氏度的零点不同（水在0°C结冰，但对应32°F），所以刻度必须先平移——这一点与长度或重量换算不同，那些只需要乘法即可。

有没有一个温度，摄氏度和华氏度是相等的？

有，在−40度。−40°C × 9/5 + 32 = −40°F，这是两个刻度唯一重合的点。在其他任何温度下，两个刻度给出的数字都不同。

这个工具也能处理开尔文吗？

可以——除了摄氏度和华氏度之外，这个工具也支持开尔文，它以绝对零度为起点，而不是一个任意设定的参考点，这使它在科学计算中非常有用。

烤箱180°C相当于多少华氏度？

精确换算是356°F，不过食谱通常会把烤箱温度四舍五入到最常见的设定值——180°C是350°F这个常见烘焙温度的标准近似值，尽管精确换算结果要略高一些。

100°F等于多少摄氏度？

约37.8°C——先减去32，再乘以5/9：(100−32)×5/9 = 68×5/9 ≈ 37.78°C。这刚好略高于人体正常体温（37°C），所以100°F在室外常常让人觉得相当炎热。

170°F等于多少摄氏度？

约76.7°C——(170−32)×5/9 = 138×5/9 ≈ 76.67°C。

73°F等于多少摄氏度？

约22.8°C——(73−32)×5/9 = 41×5/9 ≈ 22.78°C，是一个舒适的室温。

43°F等于多少摄氏度？

约6.1°C——(43−32)×5/9 = 11×5/9 ≈ 6.11°C，略高于冰箱内的温度。

43°C等于多少华氏度？

109.4°F——乘以9/5再加32：43×9/5+32 = 77.4+32 = 109.4°F，如果指的是体温，这属于高烧范围（不过健康人的体温实际上从不会达到43°C）。

73°C等于多少华氏度？

163.4°F——乘以9/5再加32：73×9/5+32 = 131.4+32 = 163.4°F。

65°F等于多少摄氏度？

约18.3°C——(65−32)×5/9 = 33×5/9 ≈ 18.33°C，是一个温和舒适的温度。

37°F等于多少摄氏度？

约2.8°C——(37−32)×5/9 = 5×5/9 ≈ 2.78°C，刚好略高于结冰点。

98°F等于多少摄氏度？

约36.7°C——(98−32)×5/9 = 66×5/9 ≈ 36.67°C，非常接近人体正常体温（约为98.6°F / 37°C）。

18°C等于多少华氏度？

64.4°F——乘以9/5再加32：18×9/5+32 = 32.4+32 = 64.4°F，是春秋季常见的温和气温。

40°F等于多少摄氏度？

约4.4°C——(40−32)×5/9 = 8×5/9 ≈ 4.44°C，是接近冰箱温度的寒冷气温。

165°C等于多少华氏度？

329°F——乘以9/5再加32：165×9/5+32 = 297+32 = 329°F，是常见的烘焙烤箱温度。

165°F等于多少摄氏度？

约73.9°C——(165−32)×5/9 = 133×5/9 ≈ 73.89°C。

65°C等于多少华氏度？

149°F——乘以9/5再加32：65×9/5+32 = 117+32 = 149°F。

106°F等于多少摄氏度？

约41.1°C——(106−32)×5/9 = 74×5/9 ≈ 41.11°C，如果指的是体温，这属于危险的高烧温度。

36.7°C等于多少华氏度？

98.06°F——乘以9/5再加32：36.7×9/5+32 = 66.06+32 = 98.06°F，非常接近人体正常体温。
