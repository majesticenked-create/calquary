Calculadora de Autovalores y Autovectores (2x2)

Introduce los cuatro elementos de una matriz 2x2 [[a, b], [c, d]] para calcular sus autovalores y autovectores.

Última actualización: August 30, 2026

Preguntas frecuentes

¿Cómo encuentro los autovalores de una matriz 2x2?

Resuelve det(A − λI) = 0, que para una matriz 2x2 [[a,b],[c,d]] se simplifica a λ² − (a+d)λ + (ad−bc) = 0 - una ecuación cuadrática en λ, usando la traza de la matriz (a+d) y determinante (ad−bc). Esta calculadora aplica esa fórmula directamente.

¿Cómo encuentro el autovector una vez que tengo un autovalor?

Resuelve (A − λI)v = 0 para el vector v - para una matriz 2x2 esto se reduce a una ecuación independiente, ya que el sistema es singular por construcción. Esta calculadora lo resuelve directamente a partir del elemento b o c y el autovalor.

¿Qué significa si los autovalores son complejos?

Autovalores complejos significan que la matriz no tiene autovectores reales - geométricamente, esto ocurre en matrices que rotan vectores (como una matriz de rotación) en lugar de simplemente estirarlos a lo largo de direcciones fijas, ya que una rotación no tiene ninguna dirección que permanezca sin cambios (excepto una rotación de 180°).
