Calculadora CIDR / Subred

Introduce una dirección IP en notación CIDR (como 192.168.1.0/24) para calcular la dirección de red, dirección de difusión, y rango de hosts utilizables de la subred.

Última actualización: August 30, 2026

Preguntas frecuentes

¿Qué significa la notación CIDR, como /24?

El número después de la barra es la longitud del prefijo - cuántos bits iniciales de la dirección IP de 32 bits están fijados como la porción de red. /24 significa que los primeros 24 bits (los primeros tres octetos) identifican la red, dejando 8 bits (256 direcciones) para hosts.

¿Cómo calculo el número de hosts utilizables a partir de un prefijo?

Hosts utilizables = 2^(32 − prefijo) − 2, restando la dirección de red y dirección de difusión, que no se pueden asignar a hosts. Una red /24 tiene 2^8 − 2 = 254 direcciones de host utilizables.

¿Por qué no hay hosts utilizables para una /31 o /32?

Una /32 es una única dirección sin espacio para un par red/difusión, y una /31 es un caso especial (definido en RFC 3021) usado para enlaces punto a punto donde ambas direcciones en el bloque de 2 direcciones son utilizables como direcciones de host, ya que no se necesita difusión.
