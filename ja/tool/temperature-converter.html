温度変換ツール

温度と変換元の単位を入力すると、華氏・摂氏・ケルビンの間で変換できます。

最終更新日： August 31, 2026

よくある質問

華氏から摂氏への変換方法は？

32を引いてから5/9を掛けます。98.6°Fの場合：(98.6 − 32) × 5/9 = 37°C（人間の平熱）です。

なぜ温度変換には掛け算だけでなくオフセットが必要なのですか？

華氏と摂氏では基準点（0度）が異なるため（水は0°Cで凍りますが、華氏では32°F）、まずスケールをずらす必要があります。これは掛け算だけで済む長さや重さの変換とは異なる点です。

摂氏と華氏で同じ数値になる温度はありますか？

−40度です。−40°C × 9/5 + 32 = −40°Fとなり、2つの目盛りが一致する唯一の点です。それ以外の温度では、両方の目盛りで異なる数値になります。

ケルビンとの相互変換にも対応していますか？

はい。摂氏・華氏に加えて、このツールはケルビンにも対応しています。ケルビンは任意の基準点ではなく絶対零度を起点とするため、科学的な計算に便利です。

オーブンの180°Cは華氏で何度ですか？

正確には356°Fですが、レシピではオーブン温度をよく使われる設定値に丸めるのが一般的です。180°Cは350°Fの標準的な丸め換算値として扱われ、これはよく使われる焼き温度です。正確な換算値はそれより数度高くなります。

100°Fは摂氏で何度ですか？

約37.8°Cです。32を引いてから5/9を掛けます：(100−32)×5/9 = 68×5/9 ≈ 37.78°C。これは人間の平熱（37°C）よりわずかに高く、100°Fが屋外でかなり暑く感じられる理由です。

170°Fは摂氏で何度ですか？

約76.7°Cです。(170−32)×5/9 = 138×5/9 ≈ 76.67°C。

73°Fは摂氏で何度ですか？

約22.8°Cです。(73−32)×5/9 = 41×5/9 ≈ 22.78°C、快適な室温です。

43°Fは摂氏で何度ですか？

約6.1°Cです。(43−32)×5/9 = 11×5/9 ≈ 6.11°C、冷蔵庫の温度より少し高い程度です。

43°Cは華氏で何度ですか？

109.4°Fです。9/5を掛けて32を足します：43×9/5+32 = 77.4+32 = 109.4°F。体温であれば高熱の範囲ですが、健康な人の体温がこの数値に達することは実際にはありません。

73°Cは華氏で何度ですか？

163.4°Fです。9/5を掛けて32を足します：73×9/5+32 = 131.4+32 = 163.4°F。

65°Fは摂氏で何度ですか？

約18.3°Cです。(65−32)×5/9 = 33×5/9 ≈ 18.33°C、穏やかで快適な温度です。

37°Fは摂氏で何度ですか？

約2.8°Cです。(37−32)×5/9 = 5×5/9 ≈ 2.78°C、氷点をわずかに上回る温度です。

98°Fは摂氏で何度ですか？

約36.7°Cです。(98−32)×5/9 = 66×5/9 ≈ 36.67°C、人間の平熱（98.6°F／37°Cに近い値）に非常に近い温度です。

18°Cは華氏で何度ですか？

64.4°Fです。9/5を掛けて32を足します：18×9/5+32 = 32.4+32 = 64.4°F、春や秋によくある穏やかな気温です。

40°Fは摂氏で何度ですか？

約4.4°Cです。(40−32)×5/9 = 8×5/9 ≈ 4.44°C、冷蔵庫に近い冷たい温度です。

165°Cは華氏で何度ですか？

329°Fです。9/5を掛けて32を足します：165×9/5+32 = 297+32 = 329°F、典型的なオーブンの焼き温度です。

165°Fは摂氏で何度ですか？

約73.9°Cです。(165−32)×5/9 = 133×5/9 ≈ 73.89°C。

65°Cは華氏で何度ですか？

149°Fです。9/5を掛けて32を足します：65×9/5+32 = 117+32 = 149°F。

106°Fは摂氏で何度ですか？

約41.1°Cです。(106−32)×5/9 = 74×5/9 ≈ 41.11°C。体温であれば危険なほどの高熱の温度です。

36.7°Cは華氏で何度ですか？

98.06°Fです。9/5を掛けて32を足します：36.7×9/5+32 = 66.06+32 = 98.06°F、人間の平熱にちょうど近い温度です。
