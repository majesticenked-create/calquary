ギブズの相律計算機

平衡状態で存在する独立成分数(C)と相の数(P)を入力します。計算機はギブズの相律F = C − P + 2を適用して自由度を求めます。

よくある質問

ギブズの相律とは何ですか?

独立成分数(C)、平衡状態で存在する相の数(P)、自由度(F)を関連付ける法則です。自由度とは、相の数を変えずに独立に変えられる、温度や圧力のような示強変数の数です。

何が成分として数えられますか?

成分とは、系の組成を記述するために必要な、独立に変化しうる化学種のことです。水のような純物質ではC = 1で、混合物は一般により多くの成分を持ちます。

何が相として数えられますか?

相とは、固体、液体、蒸気のように、物理的に区別できる均質な系の一部です。三重点の水では、3つの相が共存しています(P = 3)。

F = 0とはどういう意味ですか?

系が不変であることを意味します。固定された条件(水の三重点など)では、共存する相のうち1つを失わずに温度や圧力を変えることはまったくできません。

なぜ負の値や不可能な結果が出たのですか?

この基本形の相律でFが負になるのは、通常、与えられた成分数に対して共存すると主張された相が多すぎることを意味します。相と成分の数が平衡系と矛盾していないか確認してください。

これはギブズ自由エネルギーと同じですか?

いいえ、同じGibbsの名前を共有していても別のものです。相律は、いくつの相が共存でき、いくつの変数を独立に調整できるかに関するものです。ギブズ自由エネルギーは、系の熱力学的な有利さと自発性に関するものです。熱力学の関連分野ですが、異なる問いに答えます。
