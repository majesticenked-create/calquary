Comparaison JSON

Collez deux objets JSON pour voir une comparaison champ par champ - ce qui a été ajouté, supprimé, ou modifié entre eux.

Dernière mise à jour : August 30, 2026

Questions fréquentes

Comment fonctionne cet outil de comparaison JSON ?

Il analyse les deux objets JSON, puis parcourt récursivement chaque clé : les clés uniquement dans le premier sont marquées « Supprimé », les clés uniquement dans le second sont marquées « Ajouté », et les clés présentes dans les deux avec des valeurs différentes sont marquées « Modifié ». Les objets imbriqués sont comparés champ par champ, pas comme un seul gros bloc.

Cela compare-t-il les tableaux élément par élément ?

Les tableaux sont comparés par valeur exacte (tout le tableau est traité comme « modifié » si un élément diffère), pas fusionnés élément par élément comme les objets - cela garde la logique de comparaison prévisible pour les tableaux où l'ordre compte.

Que se passe-t-il si mon JSON a une erreur de syntaxe ?

Cet outil signale laquelle des deux entrées JSON est invalide, avec le message d'erreur de l'analyseur, plutôt que de tenter une comparaison partielle ou devinée - corrigez d'abord l'erreur de syntaxe, puis comparez.
