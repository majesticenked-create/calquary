Perguntas frequentes

Qual é a diferença entre média, mediana, e moda?

A média é a média aritmética (soma ÷ quantidade). A mediana é o valor do meio quando ordenado. A moda é o valor que ocorre com mais frequência. Todas podem diferir, especialmente com dados enviesados ou outliers.

Por que eu usaria a mediana em vez da média?

A mediana é mais resistente a outliers - um único valor extremo pode puxar a média para longe de onde a maioria dos dados realmente está, enquanto a mediana permanece ancorada ao meio dos dados ordenados independentemente de quão extremos sejam os outliers.

Um conjunto de dados pode ter mais de uma moda?

Sim - se dois ou mais valores empatam na maior frequência, o conjunto de dados é "multimodal" e todos são relatados como modas. Se cada valor aparece exatamente uma vez, não há moda significativa.

O que a amplitude te diz que a média ou mediana não dizem?

A amplitude mede a dispersão dos dados (máximo menos mínimo), enquanto média e mediana descrevem seu centro - dois conjuntos de dados podem ter médias idênticas mas amplitudes muito diferentes, refletindo quantidades de variabilidade muito diferentes.
