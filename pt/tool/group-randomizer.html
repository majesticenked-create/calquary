Randomizador de Grupos

Digite um nome por linha e escolha em quantos grupos dividi-los - cada grupo é atribuído aleatória e equitativamente.

Última atualização: August 30, 2026

Perguntas frequentes

Como isso randomiza grupos de forma justa?

Usa um embaralhamento Fisher-Yates - um algoritmo bem estabelecido que dá a cada nome uma chance igual e imparcial de acabar em qualquer posição - depois distribui a lista embaralhada em grupos em ordem round-robin, o que mantém os tamanhos dos grupos o mais equilibrados possível.

O que acontece se o número de pessoas não se dividir igualmente em grupos?

As pessoas extras são distribuídas uma por grupo começando pelo primeiro grupo, então os tamanhos dos grupos diferem em no máximo uma pessoa - para 10 pessoas divididas em 3 grupos, você obterá grupos de 4, 3, e 3, não 4, 4, e 2.

Posso usar isso para equipes de sala de aula ou divisão de projeto de trabalho?

Sim - isso funciona para qualquer cenário onde você precisa de uma divisão aleatória imparcial de uma lista de nomes em um número fixo de grupos, seja equipes de projeto de sala de aula, times esportivos, ou dividir uma lista de tarefas no trabalho.

Posso usar isso como randomizador para escolher um vencedor aleatório ou ordenar nomes aleatoriamente?

Sim - defina o número de grupos para 1, e esta calculadora embaralha toda a sua lista em uma única ordem aleatória (a forma mais justa de escolher um vencedor aleatório é pegar quem terminar primeiro). Cada novo embaralhamento usa um novo embaralhamento Fisher-Yates.

Uma 'lista randomizadora' ou 'randomizar uma lista' é a mesma coisa que esta ferramenta?

Sim - ambos descrevem embaralhar uma lista em ordem aleatória, que é o que esta ferramenta faz (defina grupos para 1 para uma única lista embaralhada, ou mais para divisões de grupo aleatórias).

'Sorteios aleatórios,' 'criador de lista aleatória,' ou 'gerador de lista aleatória' são diferentes desta ferramenta?

Não - todos esses descrevem ordenar ou sortear aleatoriamente de uma lista, que é o que esta calculadora faz. Defina grupos para 1 para embaralhar toda a lista em ordem aleatória.

'Gerador aleatório para equipes' ou 'randomizar lista' é diferente desta ferramenta?

Não - ambos descrevem dividir ou embaralhar uma lista de nomes aleatoriamente, que é exatamente o que esta calculadora faz. Defina o número de grupos para quantas equipes você precisar, ou para 1 para simplesmente embaralhar toda a lista.
