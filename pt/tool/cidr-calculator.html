Calculadora CIDR / Sub-rede

Digite um endereço IP em notação CIDR (como 192.168.1.0/24) para calcular o endereço de rede, endereço de broadcast, e faixa de hosts utilizáveis da sub-rede.

Última atualização: August 30, 2026

Perguntas frequentes

O que significa a notação CIDR, como /24?

O número após a barra é o comprimento do prefixo - quantos bits iniciais do endereço IP de 32 bits são fixados como a porção de rede. /24 significa que os primeiros 24 bits (os primeiros três octetos) identificam a rede, deixando 8 bits (256 endereços) para hosts.

Como calculo o número de hosts utilizáveis a partir de um prefixo?

Hosts utilizáveis = 2^(32 − prefixo) − 2, subtraindo o endereço de rede e endereço de broadcast, que não podem ser atribuídos a hosts. Uma rede /24 tem 2^8 − 2 = 254 endereços de host utilizáveis.

Por que não há hosts utilizáveis para uma /31 ou /32?

Uma /32 é um único endereço sem espaço para um par rede/broadcast, e uma /31 é um caso especial (definido na RFC 3021) usado para links ponto a ponto onde ambos os endereços no bloco de 2 endereços são utilizáveis como endereços de host, já que nenhum broadcast é necessário.
