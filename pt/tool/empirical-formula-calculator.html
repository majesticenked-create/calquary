Calculadora de Fórmula Empírica

Digite até três elementos e suas porcentagens de massa para calcular a fórmula empírica do composto.

Última atualização: September 1, 2026

Perguntas frequentes

O que é uma fórmula empírica?

A razão de números inteiros mais simples de átomos em um composto - por exemplo, a fórmula molecular da glicose é C₆H₁₂O₆, mas sua fórmula empírica é CH₂O, a razão reduzida.

Como calculo uma fórmula empírica a partir de porcentagens de massa?

Divida a porcentagem de massa de cada elemento pelo seu peso atômico para obter mols relativos, depois divida todos os valores de mols pelo menor para obter a razão mais simples - arredonde para números inteiros se estiverem próximos (como 1,98 → 2).

Qual é a fórmula empírica de um composto que é 40% C, 6,7% H, 53,3% O?

CH₂O - mols: C = 40/12,011 ≈ 3,33, H = 6,7/1,008 ≈ 6,65, O = 53,3/15,999 ≈ 3,33. Dividindo todos pelo menor (3,33) dá aproximadamente C₁H₂O₁, então CH₂O.

Por que minhas razões molares podem não sair como números inteiros exatos?

Arredondamento nas próprias porcentagens de massa, ou uma razão real que não é 1:1:1 (como 2:3), pode deixá-lo com valores como 1,5 ou 2,33 em vez de números inteiros - se isso acontecer, tente multiplicar todas as razões por um pequeno número inteiro (2 ou 3) para ver se caem em números inteiros.
