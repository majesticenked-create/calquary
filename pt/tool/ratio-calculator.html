Perguntas frequentes

Como simplifico uma proporção como 8:12?

Divida ambos os números pelo seu máximo divisor comum. MDC(8, 12) = 4, então 8:12 simplifica para 2:3.

Como uma proporção é diferente de uma fração?

Uma proporção compara duas quantidades diretamente (como 2:3), enquanto uma fração expressa uma quantidade como parte de um todo (como 2/3) - embora a matemática de simplificação seja a mesma.

Como escalo uma proporção para um total diferente?

Divida o total alvo pela soma das partes da proporção, depois multiplique cada parte por esse fator. Para dividir $300 em uma proporção 2:3: 2+3=5 partes, $300÷5=$60 por parte, então a divisão é $120 e $180.

Como encontro um valor ausente em uma proporção, como 3:4 = x:20?

Multiplique cruzado e resolva: 3/4 = x/20 se torna 3*20 = 4*x, então x = 60/4 = 15. Esta calculadora lida com essa multiplicação cruzada automaticamente sempre que você fornece três dos quatro valores em uma proporção.

Uma 'calculadora de proporções' é a mesma coisa que esta calculadora de razão?

Sim - uma proporção é apenas duas razões igualadas entre si, então uma calculadora de proporções e uma calculadora de razão resolvem a mesma matemática subjacente. Digite seus dois valores conhecidos acima para simplificar uma razão, ou use o FAQ de proporção acima para resolver um quarto valor ausente.

Um 'resolvedor de proporções' é diferente de uma calculadora de proporções?

Não - "resolvedor" e "calculadora" descrevem a mesma coisa aqui: encontrar um valor ausente em uma proporção, ou simplificar uma razão. Esta ferramenta lida com ambos.
