Verificador de Diferença de Cor

Insira duas cores hexadecimais para ver o quão visualmente diferentes elas são, de idênticas a muito diferentes.

Última atualização: September 1, 2026

Perguntas frequentes

Como a diferença de cor é calculada aqui?

Como a distância euclidiana entre os valores vermelho, verde e azul das duas cores, tratando RGB como coordenadas 3D: √((ΔR)² + (ΔG)² + (ΔB)²). É uma medida simples e rápida de diferença numérica.

Qual é a diferença máxima possível?

Cerca de 441,7, que é a distância entre preto puro (0,0,0) e branco puro (255,255,255): √(255² × 3) ≈ 441,7.

A distância RGB é a mesma coisa que quão diferentes as cores parecem ao olho humano?

Não exatamente - a percepção humana de cor não é uniforme no espaço RGB (somos mais sensíveis a algumas diferenças de matiz do que outras), então uma medida perceptual mais precisa como CIE Delta E pondera os componentes de forma diferente. A distância RGB é uma aproximação mais simples, "boa o suficiente" para a maioria das comparações cotidianas.

Posso usar isso para verificar se duas cores de marca são muito similares?

Sim, como uma verificação aproximada - uma distância RGB baixa (abaixo de cerca de 30) sugere cores que podem ser difíceis de distinguir, útil para sinalizar possíveis conflitos de marca ou acessibilidade antes de uma verificação perceptual mais rigorosa.
