Calculadora do Colecionador de Cupons

Digite quantos itens distintos existem (como tipos de cupons, cartas, ou prêmios) para encontrar o número esperado de sorteios aleatórios para coletá-los todos.

Última atualização: September 1, 2026

Perguntas frequentes

O que é o problema do colecionador de cupons?

Um problema clássico de probabilidade: se há n itens distintos e cada sorteio aleatório tem igual probabilidade de ser qualquer um deles (com reposição), quantos sorteios em média são necessários para coletar pelo menos um de cada item?

Qual é o número esperado de sorteios para coletar todos os 6 itens?

Cerca de 14,7 sorteios - usando sorteios esperados = n × Hₙ = 6 × (1 + 1/2 + 1/3 + 1/4 + 1/5 + 1/6) = 6 × 2,45 ≈ 14,7.

Por que fica desproporcionalmente mais difícil coletar os últimos itens?

Os sorteios iniciais provavelmente são itens novos, já que a maior parte do conjunto ainda não foi coletada, mas à medida que você coleta mais, cada novo sorteio tem uma chance cada vez menor de ser um dos poucos tipos restantes - o último item sozinho leva em média n sorteios para encontrar.

Isso assume que cada item tem igual probabilidade de ser sorteado?

Sim - este cálculo assume uma distribuição uniforme, onde cada um dos n itens tem uma chance igual de 1/n em cada sorteio. Se alguns itens são mais raros que outros, o número real esperado de sorteios será maior que esta estimativa.
