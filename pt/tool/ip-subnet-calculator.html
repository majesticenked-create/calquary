Calculadora de Sub-rede IP

Digite um endereço IPv4 e comprimento de prefixo CIDR para calcular o endereço de rede, endereço de broadcast, e faixa de hosts utilizáveis da sub-rede.

Última atualização: September 2, 2026

Perguntas frequentes

O que é um prefixo CIDR?

Um número (0-32) após uma barra indicando quantos bits iniciais do endereço IP são a porção de rede - /24 significa que os primeiros 24 bits (três octetos) identificam a rede, deixando os últimos 8 bits para endereços de host.

Quantos hosts utilizáveis uma sub-rede /24 tem?

254 - uma /24 tem 256 endereços totais (2⁸), menos o endereço de rede e endereço de broadcast, que não são atribuíveis a hosts individuais.

Qual é a diferença entre endereço de rede e endereço de broadcast?

O endereço de rede (todos os bits de host definidos como 0) identifica a própria sub-rede e não é atribuído a nenhum dispositivo. O endereço de broadcast (todos os bits de host definidos como 1) é usado para enviar uma mensagem para todos os dispositivos naquela sub-rede simultaneamente - nenhum é utilizável como endereço de host regular.

Por que sub-redes /31 e /32 não têm faixa de host utilizável?

Uma /32 tem exatamente um endereço no total (usado para identificar um único host, como uma interface loopback), e uma /31 tem apenas 2 endereços sem espaço para endereços de rede/broadcast separados - ambas são tipicamente usadas para links ponto a ponto onde cada endereço é diretamente utilizável.
