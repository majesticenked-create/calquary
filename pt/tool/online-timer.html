Perguntas frequentes

Posso executar mais de um timer ao mesmo tempo?

Sim - clique em "Adicionar outro timer" para adicionar quantas contagens regressivas independentes você precisar, cada uma com seu próprio nome, minutos/segundos e controles de iniciar/pausar/reiniciar. Todos funcionam ao mesmo tempo, para você acompanhar várias coisas de uma vez, como uma refeição de vários pratos.

Posso nomear cada timer?

Sim - cada timer tem um campo de texto acima de sua contagem regressiva onde você pode rotulá-lo (por exemplo, "Macarrão" ou "Lavanderia") para saber qual é qual quando vários estão rodando.

Este timer online continua funcionando se eu mudar de aba do navegador?

Sim - cada contagem regressiva continua em segundo plano enquanto esta aba do navegador permanecer aberta, mesmo que não seja a aba ativa. Fechar a aba ou o navegador para todos eles.

Cada timer fará seu próprio som quando terminar?

Sim - um bipe curto toca para cada timer individualmente quando sua contagem regressiva chega a zero, junto com a mudança da tela daquele timer para "Tempo esgotado!", então você sabe exatamente qual terminou.

Posso remover um timer que não preciso mais?

Sim - clique no botão × no cabeçalho de um timer para removê-lo. A página sempre mantém pelo menos um timer, então o último restante não pode ser removido.

O timer continua contando se meu computador entrar em modo de suspensão?

Não - se o dispositivo entrar em suspensão ou o navegador for suspenso, todas as contagens regressivas em execução pausam junto e retomam (um pouco atrasadas) quando o dispositivo acorda.

Posso configurar um timer para um número exato de segundos apenas, como 90 segundos?

Sim - insira 0 minutos e 90 segundos, ou 1 minuto e 30 segundos, em qualquer timer; ambos produzem a mesma contagem regressiva de 90 segundos.

Isso é o mesmo que um 'relógio de contagem regressiva' para uma data de evento específica?

Não - cada timer aqui conta uma duração fixa que você define em minutos e segundos, como um timer de cozinha. Para contar regressivamente até uma data futura específica, use uma ferramenta de contagem regressiva baseada em data.
